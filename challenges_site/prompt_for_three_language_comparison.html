Translate Trilingual with Notes

三言語対照翻訳と注釈追加

本工具能將中文訪談對話轉換為「中、英、日三語對照 HTML 網頁」，並自動偵測台灣農村特有詞彙，為跨國研究隊友補充背景解釋。

Translates Chinese transcripts into parallel trilingual HTML pages, automatically generating cultural footnotes for non-local researchers.

中国語の逐字録を「中・英・日三カ国語対照 HTML 網頁」に翻訳し、台湾農村独自の用語の背景解説を英日両言語で備考欄に自動追加します。
