Translate Trilingual with Notes

三言語対照翻訳と注釈追加

本工具能將中文訪談對話轉換為「中、英、日三語對照 HTML 網頁」，並自動偵測台灣農村特有詞彙，為跨國研究隊友補充背景解釋。

Translates Chinese transcripts into parallel trilingual HTML pages, automatically generating cultural footnotes for non-local researchers.

中国語の逐字録を「中・英・日三カ国語対照 HTML 網頁」に翻訳し、台湾農村独自の用語の背景解説を英日両言語で備考欄に自動追加します。

使用指引

Usage Guidelines

利用ガイド

跨國協作團隊在討論訪談文本時，常因為語言隔閡或文化差異（如不理解什麼是「格外品」、「契作」、「巡田水」）而導致理解落差。此 Prompt 能一鍵產生三語對照的 HTML 網頁代碼。您也可以使用下方的工具，將 AI 生成的 HTML 代碼進行即時預覽與一鍵下載！

Cross-border teams often face communication barriers due to cultural nuances. This prompt creates a parallel trilingual HTML page. You can also use the tool below to preview and download your AI-generated HTML.

多国籍チームがインタビュー結果を分析する際、台湾農民独自の用語や習慣の背景が伝わりにくいことがあります。このプロンプトは三言語対照の HTML コードを出力します。下部のツールを使用しプレビューとダウンロードも可能です。

  • 三語並列 HTML：中、英、日三欄平行對照，比對語境與翻譯極為流暢。
  • Trilingual Column Layout: Chinese, English, and Japanese side-by-side in responsive grids.
  • 三カ国語対照 HTML：中・英・日を並べて表示し、語彙の違いを視覚的に比較。
  • 即時預覽與下載：無須記事本，直接貼入下方工具，即時渲染並一鍵打包為 .html 檔案。
  • Preview & Download: No Notepad needed. Paste code below to render instantly and download with one click.
  • プレビューとDL：下部のツールに貼り付けるだけで、即座にプレビュー・ワンクリックで .html 保存。
