執行編碼與標籤化

Execute Coding & Tagging

コード化とタグ付けを実行

本工具專為將三語逐字稿進行「Coding（編碼）」所設計。透過精準標記引言與提煉小標標籤，將感性故事轉化為理性洞察。

This tool is designed to code and tag the parallel trilingual transcript, converting narratives into structured nodes.

三カ国語対照の逐字録に対して「コード化（Coding）」を行うためのツールです。發言のハイライトとタグ化を行い、分析を支援します。

使用指引

Usage Guidelines

利用ガイド

在質性研究中，Coding（編碼）就像是資訊的考古學。此 Prompt 能引導 AI 閱讀三語逐字稿，在原本的中、英、日三欄中以高亮標示出經典引言（User Quotes），並在新增的**第四欄中寫出對應的 Coding 標籤**，且該標籤本身同時包含「中 / 英 / 日」三語並列，完美突破語言障礙！

In qualitative research, coding is like information archaeology. This prompt guides AI to highlight representative quotes across original columns and write corresponding trilingual coding tags in the newly added fourth column.

質的調査において、コード化（Coding）は情報の考古学のようなものです。このプロンプトは、元の3言語対照欄で重要箇所をハイライトさせ、新設の「第4列」に対比する3言語並列のコードタグを出力させます。

  • 新設第四欄 (編碼欄)：在原本的中、英、日三欄對話右側，加入第四欄作為專用編碼區，讓引言與編碼呈現優雅平行。
  • Added 4th Coding Column: The coding workspace sits in the fourth column on the far right, matching quotes and tags side-by-side.
  • 新設の第4列 (コード欄)：元の中・英・日3つの発言列の右側に、コード専用の第4列を追加し、引用とコードを平行に対比。
  • 即時預覽與下載：複製 AI 生成的網頁代碼並貼入下方沙盒，即可當場查看精美的四欄編碼網頁，或下載成 .html 檔。
  • Preview & Download: Paste generated code in the toolbox sandbox to render instantly or download as an HTML file.
  • プレビューとDL：AI出力コードを下部ツールに貼り付けるだけで、即座にプレビュー・HTML保存。
