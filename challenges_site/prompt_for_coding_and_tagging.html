執行編碼與標籤化

Execute Coding & Tagging

コード化とタグ付けを実行

本工具專為將三語逐字稿進行「Coding（編碼）」所設計。透過精準標記引言與提煉小標標籤，將感性故事轉化為理性洞察。

This tool is designed to code and tag the parallel trilingual transcript, converting narratives into structured nodes.

三カ国語対照の逐字録に対して「コード化（Coding）」を行うためのツールです。発言のハイライトとタグ化を行い、分析を支援します。

使用指引

Usage Guidelines

利用ガイド

在質性研究中，Coding（編碼）就像是資訊的考古學。此 Prompt 能引導 AI 閱讀三語逐字稿，在原文中以高亮與粗體標示出最具代表性的引言（User Quotes），並在同一個 Coding 欄位內同時提供中英日三語對照的 `#標籤`，完美打破跨國合作的語言藩籬！

In qualitative research, coding is like information archaeology. This prompt guides AI to highlight representative quotes across languages and append corresponding trilingual parallel coding tags in the sidebar.

質的調査において、コード化（Coding）は情報の考古学のようなものです。このプロンプトは、対話データから重要発言を抽出し、サイドバーに中英日３言語対照のコードタグを自動作成します。

  • 同欄三語標籤：每一個編碼區間中，同時包含中、英、日三種語系的 `#標籤`，讓不同國籍的隊友零時差看懂分類。
  • Trilingual Parallel Tags: Each code entry bundles Chinese, English, and Japanese tags to keep global teammates aligned.
  • 同一欄の3言語タグ：各コーディングに対し中・英・日3ヶ国語のタグを併記し、多国籍メンバーの理解を均一化。
  • 即時預覽與下載：複製 AI 生成的網頁代碼並貼入下方沙盒，即可當場查看精美的雙欄編碼網頁，或下載成 .html 檔。
  • Preview & Download: Paste generated code in the toolbox sandbox to render instantly or download as an HTML file.
  • プレビューとDL：AI出力コードを下部ツールに貼り付けるだけで、即座にプレビュー・HTML保存。
